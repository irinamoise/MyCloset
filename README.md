# MyCloset

## Description
MyCloset is an application to help you manage and organize your clothing items. It allows you to add, edit, and delete items from your closet, categorize them, and keep track of what you have.

##Features:
- User authentication and profile management.
- Posting and browsing media content.
- Real-time likes and comments.
- Search functionality for specific topics.
- Sorting posts by most recent or most liked.
